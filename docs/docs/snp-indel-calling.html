Tomato PacBio HiFi Comparative Genomics Pipeline — Notes

2 SNP / InDel Calling

Dual-caller concordance strategy: DeepVariant + Clair3, intersected via bcftools isec. The concordant call set (0002.vcf) is authoritative for all downstream analysis. This is run against both MbTMV and Heinz SL4.0 alignments.

2.1 Caller 1 — DeepVariant (Singularity, batched per variety)

#single command
nohup singularity exec --cleanenv -B /data2:/data2 deepvariant_1.6.1.sif \ /opt/deepvariant/bin/run_deepvariant \
--model_type=PACBIO \
--ref=/data2/tomato/ref_genome/MbTMV_clean.fa \
--reads=/data2/tomato/MT1_aln.bam \
--output_vcf=/data2/tomato/MT1.vcf.gz \
--output_gvcf=/data2/tomato/MT1.g.vcf.gz \
--num_shards=16

##batch command
#!/bin/bash
set -euo pipefail

BASE_DIR="/data2/tomato/ref_genome/heinz"
SIF="/home/biotech/bioinfo_sware/singularity-ce-4.1.0/deepvariant_1.6.1.sif"
REF="${BASE_DIR}/clean_heinz.fasta"
NUM_SHARDS=16
VARIETIES=("CKH" "MT1" "MT3")

for VARIETY in "${VARIETIES[@]}"; do
  singularity exec --cleanenv -B /data2:/data2 "${SIF}" \
    /opt/deepvariant/bin/run_deepvariant \
    --model_type=PACBIO \
    --ref="${REF}" \
    --reads="${BASE_DIR}/${VARIETY}_aln_heinz.bam" \
    --output_vcf="${BASE_DIR}/${VARIETY}_heinz.vcf.gz" \
    --output_gvcf="${BASE_DIR}/${VARIETY}_heinz.g.vcf.gz" \
    --num_shards="${NUM_SHARDS}" \
    > "${BASE_DIR}/${VARIETY}_deepvariant.log" 2>&1
done

--model_type=PACBIO selects the HiFi/CCS-tuned model. .g.vcf.gz (gVCF) is not used in this per-sample concordance pipeline — it is only relevant for joint multi-sample genotyping (e.g., via GLnexus), which this pipeline does not currently perform.

2.2 Caller 2 — Clair3 (Singularity, batched per variety)


##single command
nohup singularity exec --cleanenv -B /data2:/data2 \
-B /home/biotech/bioinfo_sware:/bioinfo_sware \ /home/biotech/bioinfo_sware/singularity-ce-4.1.0/clair3_latest.sif \
/opt/bin/run_clair3.sh \
--bam_fn=/data2/tomato/MT1_aln.bam \
--ref_fn=/data2/tomato/ref_genome/MbTMV_clean.fa \
--threads=10 \
--platform="hifi" \
--model_path=/bioinfo_sware/Clair3/models/hifi_revio \
--output=/data2/tomato/clair3_MT1 \
--include_all_ctgs \
--gvcf &

##batch command
#!/bin/bash
set -euo pipefail

BASE_DIR="/data2/tomato/ref_genome/heinz"
TMP_DIR="/data2/tomato/tmp"
SIF="/home/biotech/bioinfo_sware/singularity-ce-4.1.0/clair3_latest.sif"
MODEL_PATH="/bioinfo_sware/Clair3/models/hifi_revio"
REF="${BASE_DIR}/clean_heinz.fasta"
THREADS=10
VARIETIES=("CKH" "MT1" "MT3")

for VARIETY in "${VARIETIES[@]}"; do
  OUTDIR="${BASE_DIR}/clair3_${VARIETY}"
  mkdir -p "${OUTDIR}"
  singularity exec --cleanenv \
    -B /data2:/data2 \
    -B /home/biotech/bioinfo_sware:/bioinfo_sware \
    -B "${TMP_DIR}:/tmp" \
    --env TMPDIR=/tmp \
    "${SIF}" \
    /opt/bin/run_clair3.sh \
    --bam_fn="${BASE_DIR}/${VARIETY}_aln_heinz.bam" \
    --ref_fn="${REF}" \
    --threads="${THREADS}" \
    --platform="hifi" \
    --model_path="${MODEL_PATH}" \
    --output="${OUTDIR}" \
    --include_all_ctgs \
    --gvcf \
    > "${BASE_DIR}/${VARIETY}_clair3.log" 2>&1
done

2.3 Concordance — bcftools isec

bcftools isec -p CKH_isec_heinz \
  CKH_heinz.vcf.gz \
  clair3_CKH/merge_output.vcf.gz
Output file Contents
0000.vcf DeepVariant-only calls
0001.vcf Clair3-only calls
0002.vcf Concordant — DeepVariant’s representation. Authoritative for downstream analysis.
0003.vcf Concordant — Clair3’s representation (same positions as 0002, redundant for most purposes)
