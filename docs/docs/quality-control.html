1 Quality Control

1.1 Read QC — NanoPlot

Run per variety on raw HiFi FASTQ/BAM input.

NanoPlot --fastq CKH.fastq.gz --outdir CKH_nanoplot --plots dot --N50 -t <threads>
NanoPlot --bam MT1_reads.bam --outdir MT1_nanoplot -t <threads>
NanoPlot --bam MT3_reads.bam --outdir MT3_nanoplot -t <threads>

What to check: total yield, read count, mean/median quality (Q-score), percentage of reads above Q20. HiFi data should show >99% reads above Q20 given the circular consensus sequencing (CCS) accuracy floor.

1.2 Index reference genome

The Heinz SL4.0 GFF3 includes ch00, an unplaced-scaffold bin (not one of the 12 real tomato chromosomes) and must be excluded from all analyses.

# Trim FASTA to ch01–ch12 only
samtools faidx Heinz_SL4.0.fasta
samtools faidx Heinz_SL4.0.fasta \
  SL4.0ch01 SL4.0ch02 SL4.0ch03 SL4.0ch04 SL4.0ch05 SL4.0ch06 \
  SL4.0ch07 SL4.0ch08 SL4.0ch09 SL4.0ch10 SL4.0ch11 SL4.0ch12 \
  > Heinz_SL4.0_genome_ch1-12.fasta
  
samtools faidx Heinz_SL4.0_genome_ch1-12.fasta

java -jar ~/bioinfo_sware/gatk-4.6.0.0/gatk-package-4.6.0.0-local.jar LocalSequenceDictionary \
clean_heinz.fasta -O clean_heinz.dict

# Trim GFF3 to the same 12 chromosomes (whitelist, not blacklist)
awk '$1 ~ /^SL4\.0ch(0[1-9]|1[0-2])$/' Heinz_SL4.0.gff3 > Heinz_SL4.0_ch1-12.gff3

1.3 Primary Alignment — pbmm2

pbmm2 index clean_heinz.fasta clean_heinz.mmi --preset SUBREAD

1.4 Mapping - pbmm2

pbmm2 align ./ref_genome/clean_heinz.mmi MT1.fastq.gz MT1_aln.bam --preset HIFI --sort \
--rg '@RG\tID:MT1\tSM:MT1\tPL:PACBIO' --unmapped -j 16 &

–preset = HIFI — correct for PacBio Revio HiFi data –sort = good, produces sorted BAM directly –sample = MT1 — correct for sample tagging -j 16 = fine for thread count .mmi = index — good, using pre-built index is faster

1.5 Secondary Alignment — ngmlr (feeds Sniffles2 SV concordance track)

ngmlr has no dedicated HiFi/CCS preset; the CLR preset (-x pacbio) is used as the closest available option.

ngmlr -t <threads> \
  -r clean_heinz.fasta \
  -q MT1.fastq.gz \
  -x pacbio \
  -o sample.sam

1.6 Index and Sorting bam file

samtools sort -@ <threads> -o MT1.aln.sorted.bam MT1.sam
samtools index MT1.aln.sorted.bam

1.7 Once indexing done, verify no corruption

samtools quickcheck /data2/tomato/MT1.aln.sorted.bam
echo $?  # 0 = good, anything else = problem

1.8 Coverage Profiling — mosdepth

Run after alignment to check per-chromosome depth before setting DP filters for variant calling.

mosdepth --threads <threads> CKH_heinz CKH.heinz.pbmm2.bam
mosdepth --threads <threads> MT1_heinz MT1.heinz.pbmm2.bam
mosdepth --threads <threads> MT3_heinz MT3.heinz.pbmm2.bam

Pull mean depth from <prefix>.mosdepth.summary.txt. A practical DP ceiling for variant filtering is roughly 2.5× the genome-wide mean depth per sample — extreme per-base depth outliers (e.g., observed on chr2/chr10 against MbTMV) typically reflect repeat-collapsed reference assembly artifacts rather than genuine sequencing problems, and should be capped rather than trusted as-is.
