Tomato PacBio HiFi Comparative Genomics Pipeline — Notes

3 Structural Variant Calling

Dual-track SV strategy: pbmm2 + pbsv as primary (HiFi-native, tandem-repeat aware), ngmlr + Sniffles2 as a secondary concordance track.

3.1 Primary Track — pbsv (tandem-repeat aware)

3.1.1 Tandem repeat annotation (once per reference)

Tandem repeats are a property of the reference sequence, not of any individual sample — generate once per reference and reuse across all varieties.

trf clean_heinz.fasta 2 7 7 80 10 50 500 -d -h

Convert TRF .dat output to BED (needed because pbsv --tandem-repeats requires BED format; TRF coordinates are 1-based inclusive and must shift to 0-based half-open):

awk '
/^Sequence:/ { seq = $2; next }
/^[0-9]+ [0-9]+/ { print seq"\t"($1-1)"\t"$2 }
' clean_heinz.fasta.2.7.7.80.10.50.500.dat > clean_heinz_tandem_repeats.bed

3.1.2 SV signature discovery + joint calling

##single command
pbsv discover \
  --tandem-repeats MbTMV_tandem_repeats.bed \
  sample.pbmm2.bam \
  sample.svsig.gz
  
##batch command
VARIETIES=("CKH" "MT1" "MT3")

for VARIETY in "${VARIETIES[@]}"; do
  pbsv discover \
    --tandem-repeats Heinz_ch1-12_tandem_repeats.bed \
    ${VARIETY}.heinz.pbmm2.bam \
    ${VARIETY}.svsig.gz
done

pbsv call \
  --num-threads <threads> \
  clean_heinz.fasta \
  CKH.svsig.gz MT1.svsig.gz MT3.svsig.gz \
  merged.pbsv.heinz.vcf

3.2 Secondary Track — ngmlr + Sniffles2 (concordance)

See the Secondary Alignment — ngmlr section above for the ngmlr alignment step and the legacy-samtools sort fix required for its SAM output.

##single cmd
sniffles --input CKH.sorted.bam --snf CKH.snf \
  --reference clean_heinz.fasta --threads <threads>

##batch cmd
VARIETIES=("CKH" "MT1" "MT3")

for VARIETY in "${VARIETIES[@]}"; do
  sniffles --input ${VARIETY}.sorted.bam --snf ${VARIETY}.snf \
    --reference clean_heinz.fasta --threads <threads>
done

3.3 Concordance Between the Two Tracks

SVs rarely land on identical coordinates across callers (unlike SNPs), so intersection uses a breakpoint-distance window rather than exact position matching:

SURVIVOR merge vcf_list.txt 1000 2 1 1 0 30 merged_survivor.heinz.vcf

3.4 Filtering

  • SUPPORT >= 3–5 supporting reads
  • SVLEN >= 50 bp (separates from indels already captured by DeepVariant/Clair3)
  • Consider tiering PRECISE vs. IMPRECISE calls separately

3.5 Statistics

##get bam stats
samtools flagstat MT1_aln.bam > MT1_aln.stats

##Count only primary alignments (excludes supplementary & secondary)
samtools view -c -F 2304 MT1_aln.bam

#to list files in singularity
singularity exec deepvariant_1.6.1.sif ls /opt/deepvariant/bin/

##obtain stats from vcf file
bcftools stats MT1.vcf.gz | grep "^SN"

##calculate stats of concordance file
bcftools stats 0002.vcf.gz | grep "^SN" > stats.txt

##retrieve number of snps
bcftools stats 0001.vcf.gz | grep "number of SNPs"

##filter
bcftools filter -e 'QUAL < 30 || DP < 10' 0002.vcf.gz -O z -o MT1_cc.vcf.gz

##for viewing
# Count total variants
bcftools view -H MT1_filtered.vcf.gz | wc -l

# View only SNPs
bcftools view -v snps MT1_filtered.vcf.gz | less

# View only indels
bcftools view -v indels MT1_filtered.vcf.gz | less

# Quick stats summary
bcftools stats MT1_filtered.vcf.gz | grep "^SN"

3.6 Notes on Interpretation

  • GT is authoritative over ALT for allele determination in single-sample VCFs — phantom ALT alleles can arise from repeat-collapsed reference assembly artifacts.
  • NA in a joined sample column means “matches reference,” not missing data.
  • A high multiallelic site count in what should be a single-sample VCF likely indicates the file is actually a merged multi-sample VCF.
  • HiFi’s ~99.9% raw accuracy is mostly a substitution-error improvement; residual error remains disproportionately indel-based, especially in homopolymer runs. True biological coding-region indels cluster at multiples of 3 bp (frame-preserving); artifact indels cluster at 1–2 bp in homopolymer contexts — a useful QC check with no direct SNP-Ts/Tv equivalent.
